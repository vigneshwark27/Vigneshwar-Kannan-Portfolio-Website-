PRD — Chargebee: Contract-to-Subscription using AI feature

👤AuthorVigneshwar Kannan
📅Year2025
🏷️StatusIn Review
🔧TypePersonal Project · B2B SaaS
💡

This project introduces an optional Contracts add-on that helps billing users convert signed contract PDFs into draft subscriptions using AI, reducing manual effort while preserving existing subscription creation and billing workflows.

🎯 Goals & Key Performance Indicators

Goals

  • Reduce manual effort required to create subscriptions from contracts
  • Improve accuracy and consistency between signed contracts and system data
  • Speed up subscription setup without increasing billing risk

Key Performance Indicators

  • Reduction in average time to create a subscription from a contract
  • Decrease in billing errors
  • Adoption rate of the Contracts module among billing teams
  • Percentage of draft subscriptions successfully confirmed by users

🚧 Constraints

  • Subscriptions must not be auto-activated — human confirmation is mandatory
  • Existing subscription creation and billing workflows must remain unchanged
  • AI assistance is limited to pre-creation stages only
  • Contracts can vary widely in format, structure, and language
  • The feature must integrate as an add-on, not a core dependency

🧩 Assumptions

  • Users are billing or revenue operations professionals familiar with subscription concepts
  • Uploaded contracts are signed and represent agreed commercial terms
  • The uploaded contract document must contain keywords that can be mapped to subscription fields
  • Users expect AI to assist, not replace, their judgment
  • Master data (customers, products, plans) are typically pre-configured or can be created during the flow

🔗 Dependencies

  • Availability of existing customer and product catalog and Plans within the system
  • Access to a contract storage mechanism for uploaded PDFs
  • Integration with the existing Create Subscription flow
  • AI extraction services capable of identifying subscription-related terms
